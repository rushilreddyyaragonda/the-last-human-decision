# The Last Human Decision

Narrative strategy simulation about automation, public trust, research, investment, and the consequences of high-stakes decisions.

## Analysis

- **Core experience:** campaign selection, briefing, event decisions, policy and investment panels, research, public sentiment, society map, analytics, history, and multiple endings.
- **Technical approach:** React + TypeScript + Vite, a typed game state, seeded randomness, campaign/event content, persistence, research and ending engines.
- **Portfolio value:** demonstrates stateful product design, narrative systems, simulation logic, and the ability to make abstract social questions playable.
- **Current health:** production build and TypeScript check pass. ESLint reports existing unused symbols and a small number of type/style issues.

## Run locally

```bash
npm install
npm run dev
```
